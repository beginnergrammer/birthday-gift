BIRTHDAY GIFT WEBSITE
=====================

Made as a cute mobile-first birthday surprise.

1. TEST LOCALLY
---------------
Open index.html in a browser, or use a simple local server.

Code: 5923

2. ANTIGRAVITY
--------------
Open the project folder in Antigravity and run index.html / your preferred local preview.

3. ADD MEMORY PHOTOS LATER
---------------------------
The Memories page currently has four cute placeholders.
You can replace each placeholder with a real photo in:

images/memories/

The HTML is in index.html inside the section:

<section class="screen overlay-screen" data-screen="memories">

Search for "Memory 01", "Memory 02", etc. when you are ready.

4. REFERENCE IMAGES
-------------------
The original reference screenshots you provided are kept in:

reference/1.jpeg ... reference/9.jpeg

They are only reference files and are not displayed in the website.

5. IMPORTANT
------------
- The secret code is 5923 in js/app.js.
- This is a static surprise website, not a real security system.
- No database or backend is required.
- The Google Fonts link needs internet access. If you want a fully offline version later, the fonts can be bundled locally.
- The sound button currently provides tiny browser-generated UI sounds; there is no external music file yet.
